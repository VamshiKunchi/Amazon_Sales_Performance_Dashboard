# 🛒 Amazon Sales Performance Dashboard

Welcome to the **Amazon Sales Performance Dashboard** - an interactive Power BI project designed to analyze Amazon sales performance, revenue trends, product categories, and customer reviews. The dashboard provides clear business insights through KPIs, charts, and interactive filters.

## 📊 Dashboard Overview

![Amazon Sales Dashboard](https://raw.githubusercontent.com/VamshiKunchi/Amazon_Sales_Performance_Dashboard/main/Dashboard%20Image.png)

## 🔍 Key Highlights

- **KPIs:** YTD Revenue, QTD Revenue, YTD Units Sold, and Product Reviews.
- **Charts Included:**
  - Monthly Sales Trend
  - Weekly Sales Trend
  - Category-wise Sales Performance
  - Top 5 Products by Revenue
  - Top 5 Most Reviewed Products
- **Filters:**
  - Product Category
  - Quarter

## 💼 Tools & Technologies

- **Power BI** – Interactive dashboard and data visualization
- **DAX** – Calculated measures and KPIs
- **Power Query** – Data cleaning and transformation
- **Excel** – Data preparation and analysis

## 📁 Dataset

The dataset contains Amazon sales and product-related information, including:

- Product Name
- Product Category
- Sales / Revenue
- Quantity Sold
- Product Reviews
- Date / Month
- Quarter

📌 _Note: The dataset is used for personal portfolio and learning purposes._

## 🎯 Project Objective

The main objective of this project is to analyze Amazon sales data and create an interactive dashboard that helps users:

- Monitor overall sales performance
- Track monthly and weekly revenue trends
- Identify high-performing product categories
- Identify top-performing products
- Compare YTD and QTD performance
- Analyze product review performance

## 📈 Key Insights

- **Men Shoes** generated the highest revenue among the analyzed categories.
- **Camera** was one of the leading revenue-generating categories.
- Sales performance varied across different months and weeks.
- The dashboard highlights the top products based on revenue and customer reviews.
- Interactive filters allow users to explore sales performance by category and quarter.
